cosmetics website, a beauty studio draft, and introductory Git exercises.

## Projects

  website.
- `stefies-beauty-studio/` - Stefie's Beauty Studio website.
- `beauty-salon-draft/` - Early beauty salon page draft.
- `index.html`, `about-my-website.html`, and `stefies.css` - Introductory

- `beauty-shop-draft.html` - Early beauty shop page draft.
