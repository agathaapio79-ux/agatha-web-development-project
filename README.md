# Web Development Project

This repository brings together my HTML and CSS practice work. It includes a
responsive cosmetics website, a beauty studio concept, and a few early drafts
as I learn to build and organize web pages.

## Start here

Open [`index.html`](./index.html) for the project landing page. The main
multi-page website is in [`agatha-beauty/`](./agatha-beauty/); open its
`index.html` to begin.

## Projects

- [`agatha-beauty/`](./agatha-beauty/) - The responsive Agatha beauty website,
  with home, about, products, and contact pages.
- [`agatha-beauty-basic/`](./agatha-beauty-basic/) - A simpler, unstyled
  version of the same site.
- [`agatha-beauty-studio/`](./agatha-beauty-studio/) - Agatha's Beauty Studio
  concept.
- [`beauty-salon-draft/`](./beauty-salon-draft/) and
  [`beauty-shop-draft.html`](./beauty-shop-draft.html) - Early design drafts.
- [`about-my-website.html`](./about-my-website.html) - Notes about this
  collection of practice projects.
